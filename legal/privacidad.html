2. Qué datos se tratan, para qué y con qué base legal

Al visitar la web

combinario.es está alojada en GitHub Pages (GitHub, Inc., Estados Unidos). Como cualquier servidor, GitHub recibe la dirección IP de quien visita la web y la registra por seguridad. El titular no usa esos registros. Base legal: interés legítimo en que la web funcione y sea segura (artículo 6.1.f del Reglamento General de Protección de Datos, RGPD). GitHub se acoge al Marco de Privacidad de Datos UE-EE. UU. y a cláusulas contractuales tipo para enviar datos fuera de la Unión Europea.

La web no tiene formularios, ni analítica, ni publicidad, ni botones de redes sociales.

Si nos escribes

Si escribes a combinario.es@gmail.com, usamos tu dirección y lo que nos cuentes solo para responderte. Base legal: tu propia petición (artículo 6.1.b del RGPD). El correo lo gestiona Google, que presta el servicio de Gmail. Guardamos los mensajes mientras haga falta para atender tu consulta y, como mucho, un año después, salvo que una ley obligue a guardarlos más tiempo.

Al usar la aplicación

  • Sin registro. La aplicación no pide nombre, correo ni teléfono.
  • Tus jugadas se quedan en tu móvil. Jugadas, boletos guardados y ajustes se guardan solo en tu dispositivo.
  • Datos que descarga. Para resultados, botes, jornadas y listas de Lotería Nacional, la aplicación se conecta a combinario.es y, cuando es posible, a la web pública de Loterías y Apuestas del Estado. Para partidos y clasificaciones usa un servicio público de datos deportivos (ESPN). La aplicación web y la de Android cargan los tipos de letra desde Google Fonts (Google). En esas conexiones, como en cualquier visita a una web, esos servicios reciben la dirección IP del móvil; la aplicación no les envía ningún otro dato tuyo.
  • Cámara. Solo se usa para leer códigos QR y de barras. Las imágenes no se guardan ni se envían.
  • Informes de fallos. Si la aplicación falla, envía un informe a Sentry (Functional Software, Inc.) con el error, la pantalla, la versión y el tipo de sistema, sin tus jugadas ni datos tuyos. Los informes se guardan en la Unión Europea (Fráncfort). Base legal: interés legítimo en arreglar los fallos (artículo 6.1.f del RGPD). Puedes desactivarlo en Más › Ajustes.

3. A quién se ceden los datos

A nadie, salvo obligación legal. Los proveedores citados (GitHub, Google y Sentry) tratan los datos solo para prestar su servicio.

4. Menores

La web y la aplicación son solo para mayores de 18 años.

5. Tus derechos

Puedes pedir acceder a tus datos, corregirlos, borrarlos, oponerte a su uso, limitarlo o llevártelos, escribiendo a combinario.es@gmail.com. Si crees que no hemos atendido bien tu petición, puedes reclamar ante la Agencia Española de Protección de Datos (www.aepd.es).

No tomamos decisiones automáticas sobre ti ni hacemos perfiles, y no vendemos datos.

6. Cambios

Si cambia algo de esta política, lo publicaremos aquí con la fecha de la actualización.

Combinario es una aplicación independiente: no es oficial ni tiene relación con Loterías y Apuestas del Estado (SELAE). No vende apuestas. Solo para mayores de 18 años.
